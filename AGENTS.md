<h1>Repository Guidelines</h1><h2>Project Structure</h2>React and TypeScript source is in src/, public assets in public/, and Supabase migrations in supabase/migrations/. <h2>Commands</h2>Use npm install, npm run dev, npm run lint, npm run build, and npm run preview for dependencies, development, lint, production build, and preview. No automated test runner is configured. <h2>Style and Testing</h2>Use TypeScript function components and follow ESLint and nearby patterns. Components use PascalCase; functions use camelCase. Manually check affected flows, then run lint and build. <h2>Commits and Pull Requests</h2>Use focused imperative commit subjects. Describe changes and checks in pull requests; include screenshots for UI changes and identify database changes. <h2>Security</h2>Never commit .env or secrets. Keep OPENAI_API_KEY in the Edge Function environment. Review docs/SUPABASE_MIGRATION_RECONCILIATION.md and back up before production database changes.
